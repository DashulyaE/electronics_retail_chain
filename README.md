# Модель сети по продаже электроники 
## Описание проекта: ##
Этот проект реализует API для управления цепочкой поставок электроники, включает модели контактов, 
продуктов и звеньев сети, а также административную панель.

## Технические требования ##
- Python 3.8+
- Django 3+
- DRF 3.10+
- PostgreSQL 10+
- 
## Установка:

1. Клонируйте проект в свой репозиторий по ссылке:
```
git clone github.com/DashulyaE/electronics_retail_chain
```
2. Установите зависимости
```
poetry install
```
3. Создайте миграции
```
python manage.py makemigrations
python manage.py migrate
```
4. Создайте суперполльзователя
```
python manage.py createsuperuser
```
и введите логин, email и пароль

5. Запуск сервера
```
python manage.py runserver
```
и перейдите по адресу
```
http://127.0.0.1:8000/
```
6. Доступ к админке
```
http://127.0.0.1:8000/admin/
```

## Документация ##

Ознакомиться с документацией проекта можно, запустив сервер коммандой в терминале:
```
python manage.py runserver
```
И введя адрес в браузере:
```
http://127.0.0.1:8000/swagger/
```
